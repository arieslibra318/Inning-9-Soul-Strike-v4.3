## 🎮 遊戲簡介

本專案為 **8-Bit 像素復古風格的棒球 QTE（Quick Time Event）即時反應打擊遊戲**。
玩家需在投手上壘投球的瞬間，根據畫面提示的節奏判定圈，於最佳判定時機按下打擊鍵，挑戰連續安打並力求擊出九局下半的逆轉滿貫全壘打！

---

## 🌟 核心特色 (v4.3 更新重點)

* **像素動畫視頻融合**：
  * Stage 1：首發試煉（8-bit 初登場投手對決）
  * Stage 2：進入得點圈緊湊對峙
  * Stage 3：終極逆轉滿貫全壘打（Grand Slam 震撼演出）
* **精準 QTE 判定機制**：Perfect / Great / Good / Miss 多段反饋判定。
* **純前端跨平台相容**：單一 HTML + 影音素材，支援電腦鍵盤（空白鍵 / Enter）與手機觸控點擊操作。

---

## 🕹️ 遊玩方式

1. **本機直接遊玩**：下載本儲存庫後，直接點擊兩下 `index.html` 即可在任一現代瀏覽器（Chrome, Edge, Safari）暢玩！
2. **操作說明**：
   * **PC 端**：使用 `空白鍵 (Space)` 或 `滑鼠左鍵` 點擊擊球。
   * **行動端**：直接點擊螢幕任何位置進行揮棒。
